llama-harness for Rust

Build bounded local agent workflows without handing control of tools, policy, data, or user experience to a framework.

Install the crate Embedding guide
Installation

Add the supported facade

Use llama-harness as the single application dependency. Default features are empty, so integrations are always explicit.

Cargo.toml 
[dependencies]
llama-harness = { version = "0.2.0", features = ["ollama"] }
tokio = { version = "1", features = ["macros", "rt-multi-thread"] }
0.2.0 release candidate.

Use the registry dependency only after 0.2.0 is published. For pre-release source builds, pin the exact commit approved by your release process; do not depend on a mutable branch.

Quick start

Run a local Ollama model

Ollama and the selected model must already be installed and running. The provider accepts loopback URLs only and does not download models.

  1. Enable the ollama feature.This exposes llama_harness::ollama.
  2. Create a provider and runner.Your application can add tools, policy, approvals, and events.
  3. Execute a request.The runner returns a typed result and respects cancellation and limits.
Rust 
use std::sync::Arc;
use llama_harness::{
    ollama::OllamaProvider, AgentDefinition, AgentRunner, RunRequest,
};

let provider = Arc::new(OllamaProvider::new()?);
let runner = AgentRunner::builder(provider).build();
let agent = AgentDefinition::new(
    "assistant", "Assistant", "1", "qwen3:8b"
);
let result = runner
    .run(RunRequest::new(agent, "Say hello."))
    .await?;
Architecture

Your application stays in charge

llama-harness runs inside your process. It provides the reusable model-and-tool loop while keeping product and capability decisions at the application boundary.

Your application owns

  • Tools and accessible data
  • Policy and approval decisions
  • Provider credentials and models
  • User interface and event presentation

The harness manages

  • Model and tool-call sequencing
  • Schema validation and bounded retries
  • Limits, deadlines, and cancellation
  • Typed results and ordered causal events
