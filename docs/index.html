CORE API

AgentRunner

Rust

The embedded engine is the source of truth. Construct a runner in your Rust or Tauri process, register application-owned tools, and execute a bounded run.

AgentRunner::builder

Configure the model provider, policy, approval handler, limits, and event sink.

Read embedding guide →
runner.run(request)

Execute one agent request and receive a typed result with ordered causal events.

See architecture →
runner.cancel(run_id)

Cancel a known run. Cancellation is propagated through pending model and callback waits.

Review controls →
Rust
let runner = AgentRunner::builder(provider).build();
let result = runner.run(request).await?;
println!("{}", result.final_output.unwrap_or_default());
CONTROL PLANE

Tools, policy, and approvals

Fail closed

Tool schemas are validated before execution. Policy runs before approval, state-changing tools require explicit authorization, and callback failures terminate safely.

ConceptWhat it controlsDefault
ToolSchema, arguments, read-only declaration, executionApplication-owned
PolicyEngineWhether a proposed call is allowedRead-only safe default
ApprovalHandlerUser or host confirmation for risky actionsDeny if missing
AgentLimitsCalls, tokens, duration, output and input boundsExplicit per run
OBSERVABILITY

Runs and events

Ordered

Each run emits structured, ordered events. Attach a redacted local SQLite sink when you need trace inspection; chain-of-thought is never collected.
